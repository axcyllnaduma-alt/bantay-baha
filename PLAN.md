# Bantay Baha - Sprint Plan

## 1. User Stories & 2. Acceptance Criteria

**Story 1 (Resident):** As a resident, I want to see the current water level and trend on my phone so that I know if I need to evacuate.
* **Criteria 1:** Water level is displayed clearly in centimeters.
* **Criteria 2:** Trend (rising, falling, or steady) is visible on the screen.
* **Criteria 3:** The app is mobile-responsive and fits a 375px screen perfectly.

**Story 2 (Barangay Official):** As a barangay official, I want a plain-language advisory generated from the data so that I can quickly inform the community.
* **Criteria 1:** Clicking the advisory button generates a response in English and Filipino.
* **Criteria 2:** If the AI fails, a rule-based fallback advisory is shown.

**Story 3 (Resident):** As a resident, I want the dashboard to auto-refresh so that I get real-time updates without manually reloading.
* **Criteria 1:** The page pulls new data every 5 seconds.
* **Criteria 2:** The latest 10 readings table and line chart update automatically.
